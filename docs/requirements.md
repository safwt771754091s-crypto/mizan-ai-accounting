# المتطلبات — RAKAZ AI

## 1. الهدف

منصة SaaS عربية تساعد المحاسب القانوني وصاحب المنشأة على:

1. استيراد ملفاته المحاسبية (Excel/CSV/PDF) دون إعادة إدخال يدوي.
2. الحصول على ميزان مراجعة وقوائم مالية دقيقة قابلة للتتبع.
3. اكتشاف الأخطاء والقيود المكررة والعمليات غير المعتادة.
4. قراءة تحليل مالي مبني على معادلات معلنة.
5. إصدار تقرير عربي احترافي قابل للتصدير.
6. سؤال مساعد ذكي يُجيب من بيانات الشركة نفسها فقط.

## 2. المستخدمون والأدوار

| الدور | الصلاحيات |
| --- | --- |
| `owner` | كل شيء داخل الشركة، بما فيه إدارة الأعضاء والإعدادات |
| `admin` | إدارة البيانات والاستيراد والتقارير، دون حذف الشركة |
| `accountant` | استيراد ومراجعة وتقارير |
| `auditor` | قراءة + مراجعة الملاحظات، دون تعديل القيود |
| `viewer` | قراءة فقط |

المستخدم يمكن أن ينتمي إلى أكثر من شركة بدور مختلف في كل واحدة. المستخدم الفائق (`isSuperAdmin`)
يدير المنصة، ولا يرى بيانات شركة لا ينتمي إليها.

## 3. المتطلبات الوظيفية

### 3.1 الشركات
- إنشاء/تعديل شركة: الاسم، الاسم القانوني، النشاط، الدولة، العملة، السنة المالية، نوع المنشأة، الحالة.
- أكثر من شركة للمستخدم، ومبدّل شركة ثابت في الواجهة.
- فصل بيانات صارم: لا يستطيع مستخدم قراءة أو تعديل بيانات شركة ليس عضواً فيها.

### 3.2 الاستيراد
- رفع XLSX / XLS (نصي) / CSV / PDF نصي، بحد 15MB.
- أنواع البيانات: ميزان المراجعة، دفتر الأستاذ، القيود اليومية، المبيعات، المشتريات،
  المصروفات، العملاء، الموردون، المخزون، كشف البنك.
- خطوات: اختيار النوع ← تحليل الملف ← اختيار الورقة ← اكتشاف الأعمدة وربطها ← معاينة
  وتحقق ← تأكيد ← حفظ مع سجل مصدر (ملف/ورقة/صف/دفعة).
- منع التكرار عبر بصمة SHA-256 لكل (شركة، نوع بيانات، ملف).
- لا يُستورد أي صف به خطأ يمنع الاستيراد؛ تُعرض التحذيرات قبل التأكيد.

### 3.3 المحاسبة
- دليل حسابات هرمي مع أنواع (أصول، التزامات، حقوق ملكية، إيرادات، مصروفات) وتصنيفات فرعية.
- قيود يومية متوازنة، ترحيل، فترات مالية، أرصدة افتتاحية وختامية.
- ميزان مراجعة بالمجاميع والأرصدة، شهري وسنوي، قبل/بعد التسويات عند توفرها.
- قائمة دخل، مركز مالي، تدفقات نقدية (عند كفاية البيانات)، تغيرات حقوق الملكية.
- تحقق تلقائي: الأصول = الالتزامات + حقوق الملكية، وعرض الفرق.

### 3.4 الفحص والمراجعة
- كشف: قيود غير متوازنة، حسابات غير موجودة/غير مصنفة، أرصدة غير طبيعية، تواريخ خارج
  الفترة، بيانات ناقصة، فروقات ميزان المراجعة، قيود بصفر أو بسطر واحد.
- كل ملاحظة: عنوان، وصف، حساب، قيد، مصدر، خطورة، سبب، توصية، حالة مراجعة.
- كشف التكرار بمعايير متعددة (رقم، تاريخ، مبلغ، طرف، تشابه الوصف) بدرجات قوة.
- تحليل مخاطر المصروفات بقواعد قابلة للتخصيص.
- لا حذف أو تعديل تلقائي لأي قيد.

### 3.5 التحليل والتقارير
- نسب سيولة وربحية ومديونية ودوران، مع إخفاء أي نسبة لا تكفي بياناتها وإظهار المعادلة.
- رسوم Recharts مرتبطة ببيانات الشركة الفعلية.
- تقرير شامل من 20 قسماً مع تصدير Excel وطباعة/PDF.

### 3.6 المساعد الذكي
- يجيب عن أسئلة مالية من سياق الشركة الحالية وصلاحيات المستخدم.
- كل رقم مستمد من المحرك؛ لا حساب داخل النموذج اللغوي.
- يذكر المصادر ويصرّح بأن النتائج مساعدة وليست رأياً قانونياً.
- لا يعدّل أو يحذف بيانات.

## 4. المتطلبات غير الوظيفية

| المتطلب | المعيار |
| --- | --- |
| دقة مالية | Decimal.js، لا أرقام عشرية عائمة في الحسابات |
| اللغة | واجهة عربية RTL كاملة، أرقام مالية واضحة |
| الاستجابة | تعمل على الهاتف والحاسوب |
| الأمن | RLS، تحقق من الملفات، رؤوس أمان، لا أسرار في المستودع |
| الأداء | معالجة ملفات حتى 5000 صف في المعاينة، وبناء القوائم من الذاكرة |
| القابلية للاختبار | محرك مستقل عن الواجهة + 105 اختبار وحدة + 12 E2E |
| التوسع | مستودع مجرد (Demo/Supabase)، وحدات مستقلة، بنية وكيل قابلة للتوسع |

## 5. خارج النطاق (النسخة الحالية)

- OCR للملفات الممسوحة.
- تعدد العملات مع إعادة تقييم تلقائية.
- إقرارات ضريبية إلكترونية.
- توقيع إلكتروني أو اعتماد قانوني للتقارير.
