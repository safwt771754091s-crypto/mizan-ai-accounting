# الاختبارات — Mizan AI

## 1. اختبارات الوحدة (Vitest)

```bash
npm test
```

الملفات في `src/tests/`:

| الملف | ما يختبره |
| --- | --- |
| `money.test.ts` | الدقة العشرية، التقريب، التنسيق |
| `engine.test.ts` | تجميع القيود، الأرصدة، توازن ميزان المراجعة |
| `statements.test.ts` | قائمة الدخل، المركز المالي، معادلة الميزانية، التدفقات |
| `ratios.test.ts` | النسب، إخفاء النسب غير القابلة للحساب |
| `findings.test.ts` | كل قواعد الفحص والخطورة |
| `duplicates.test.ts` | درجات التكرار وعدم اعتبار الاشتراكات الشهرية تكراراً |
| `anomalies.test.ts` | ارتفاع المصروف، الشذوذ، المبالغ المتكررة، التركّز |
| `import.test.ts` | قراءة CSV/XLSX، اكتشاف الأعمدة، التحقق، بناء القيود |
| `repository.test.ts` | العضوية، الأدوار، عزل الشركات، منع تكرار الاستيراد |
| `reports.test.ts` | اكتمال أقسام التقرير واتساق أرقامه |
| `assistant.test.ts` | نيات الأسئلة، ذكر المصادر، منع اختلاق الأرقام |
| `demo-data.test.ts` | توازن البيانات التجريبية واتساقها |
| `seed.test.ts` | بناء/إعادة بناء مخزن البيانات التجريبية |

القاعدة: تُستخدم بيانات تجريبية مُصنّعة داخل `fixtures.ts`، ولا تُستخدم أي بيانات عملاء حقيقية.

## 2. اختبارات E2E (Playwright)

```bash
npx playwright install chromium   # مرة واحدة
npm run test:e2e
```

- الخادم يعمل تلقائياً على المنفذ `3100` بوضع `MIZAN_DATA_MODE=demo`.
- `reuseExistingServer` مفعّل، لذا لا تترك خادماً على 3100 أثناء التطوير إلا إذا أردت
  استخدامه.
- التتبع والصور تُحفظ عند الفشل في `test-results/`.

| الملف | السيناريو |
| --- | --- |
| `auth.spec.ts` | خطأ كلمة المرور، الدخول، حماية المسارات، عزل المشاهد |
| `navigation.spec.ts` | 16 صفحة تُفتح بعناوينها، وتبديل الشركة يغيّر البيانات |
| `import.spec.ts` | رفع CSV حقيقي ← اكتشاف أعمدة ← تأكيد ← ظهور الملف في سجل الاستيراد؛ ورفض `.exe` |
| `assistant.spec.ts` | إجابة برقم فعلي وعملة ومصدر، وإجابة التكرار دون ادعاء حذف |
| `reports.spec.ts` | أقسام التقرير + تنزيل XLSX فعلي + توازن ميزان المراجعة |

## 3. الفحوص قبل الدمج

```bash
npm run lint && npm run typecheck && npm test && npm run build && npm run test:e2e
```

النتيجة الحالية:

```text
ESLint        ✅ بلا أخطاء أو تحذيرات
tsc --noEmit  ✅
Vitest        ✅ 105 اختباراً في 13 ملفاً
next build    ✅
Playwright    ✅ 12 اختباراً
```

## 4. ما لا تغطيه الاختبارات بعد

- اختبار حمل لملفات كبيرة جداً.
- اختبار RLS على مشروع Supabase حقيقي (السياسات مكتوبة لكن تحتاج تحققاً بمشروع فعلي).
- اختبار PDF الممسوح ضوئياً (غير مدعوم).
- اختبار مساعد LLM حقيقي (يتطلب مفتاح مزود).
